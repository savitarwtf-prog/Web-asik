## Objective
The goal of this assignment is to build and deploy a basic webpage from scratch using HTML5 and CSS3. The project demonstrates text structure, lists, tables, forms, CSS styling, the Box Model, positioning, float layout techniques, and publication via GitHub Pages.

---

## Summary of Work Process
I developed a personal portfolio webpage (`index.html`) and styled it using an external stylesheet (`style.css`). The development process was broken down into four key stages:
1. Setting up the base HTML structure and basic content elements.
2. Expanding HTML with intermediate elements such as schedule tables and contact forms.
3. Applying CSS rules using inline, internal, and external approaches with various selectors.
4. Structuring the layout using CSS Box Model, positioning, sizing units, and floats, followed by deploying the site to GitHub Pages.
